# ダンジョンダイスクロニクル 体験版

ブラウザで遊べる体験版の静的配布ファイルです。

## GitHub Pages

このリポジトリは、`main` ブランチのルートを GitHub Pages から直接公開する構成です。ビルド処理や GitHub Actions は必要ありません。

## ローカル確認

このディレクトリで次のコマンドを実行し、表示されたローカル URL をブラウザで開きます。

```powershell
python -m http.server 8000
```

セーブデータとデッキ設定はブラウザの `localStorage` に保存されます。同じブラウザ・同じ公開 URL では、ページを再読み込みしても保存内容が維持されます。ブラウザのサイトデータを削除した場合や、公開 URL が変わった場合は別の保存領域として扱われます。

## 公開上の注意

GitHub Pages と公開リポジトリでは、HTML、JavaScript、画像、音声などの配布ファイルを第三者が閲覧・取得できます。
